# Palindrome Number Checker in Java 🔄

A clean, efficient, and well-documented Java program designed to check if a given integer is a palindrome. This project serves as an excellent reference for understanding arithmetic logic, number reversal, and conditional structures in Java without using built-in string reversal functions.

## 🚀 Features

* **Palindrome Validation:** Checks if a number reads the same backward as forward.
* **Efficient Logic:** Reverses the integer mathematically using arithmetic operators (`%` and `/`) to optimize memory usage.
* **Negative Number Handling:** Properly accounts for negative signs, which inherently prevent a number from being a true palindrome.

## 🛠️ Built With

* **Java Development Kit (JDK):** Version 8 or higher

## 💻 Getting Started

### Prerequisites
Make sure you have the Java Development Kit (JDK) installed on your system. Verify by running:
```bash
java -version
```

### Installation & Execution
1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the project folder:
   ```bash
   cd YOUR_REPOSITORY_NAME
   ```
3. Compile the Java source file:
   ```bash
   javac Palindrome.java
   ```
4. Run the compiled application:
   ```bash
   java Palindrome
   ```
